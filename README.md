# dsh-advanced-model-editor

Pre-built distribution package for **dsh-advanced-model-editor** (Advanced Model Settings plugin for DeepSeek Harness WebUI).

For full documentation, screenshots, and source code, visit the GitHub repository:

👉 **https://github.com/u9521/dsh-advanced-model-editor**

## Quick Install

```sh
dsh plugin --profile web add github:u9521/dsh-advanced-model-editor#dist
```

Then restart web (`dsh web`) and hard-refresh your browser (Cmd+Shift+R).
